# Dinoster Arena

Небольшая 2D arena-brawler игра для ребёнка, вдохновлённая идеей динозавров-супергероев. Целевая платформа — браузер на компьютере и планшете.

Проект начинается с минимального вертикального среза: одна арена, один герой, один AI-соперник, движение, одна атака, здоровье, KO и рестарт.

> Репозиторий публичный и не содержит защищённых материалов мультфильма. На ранних этапах используются геометрические заглушки; финальные ассеты должны быть оригинальными или лицензированными.

## Стек

- Phaser 4.2.1
- TypeScript 5.9.2
- Vite 7.1.0
- Arcade Physics

## Запуск

Требуется Node.js 20.19 или новее.

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite. Для доступа с планшета компьютер и планшет должны быть в одной сети; используй сетевой адрес Vite.

Проверка production-сборки:

```bash
npm run build
npm run preview
```

После первого `npm install` закоммить созданный `package-lock.json`.
