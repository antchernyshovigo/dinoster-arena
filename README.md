# Dinoster Arena

Небольшая 2D arena-brawler игра для ребёнка, вдохновлённая идеей динозавров-супергероев. Целевая платформа — браузер на компьютере и планшете.

Проект начинается с минимального вертикального среза: одна арена, один герой, один AI-соперник, движение, одна атака, здоровье, KO и рестарт.

> Репозиторий публичный и не содержит защищённых материалов мультфильма. На ранних этапах используются геометрические заглушки; финальные ассеты должны быть оригинальными или лицензированными.

## Стек

- Phaser 4.2.1
- TypeScript 5.9.2
- Vite 7.1.0
- Arcade Physics

## Запуск

Требуется Node.js 20.19 или новее.

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite. Для доступа с планшета компьютер и планшет должны быть в одной сети; используй сетевой адрес Vite.

Проверка production-сборки:

```bash
npm run build
npm run preview
```

После первого `npm install` закоммить созданный `package-lock.json`.

## Текущий этап

M4 — планшетное управление — завершён. Сейчас реализованы:

- движение игрока по 2.5D-плоскости;
- атаки игрока и AI-соперника;
- здоровье и получение урона;
- состояния HIT и KO;
- результаты «Победа» и «Поражение»;
- повторный запуск раунда кнопкой «Играть ещё», клавишей Enter или R;
- экранные стик и кнопка атаки с поддержкой multi-touch;
- первый оригинальный герой «Кварц» с анимациями `idle`, `move`, `attack`, `hit` и `ko`.

Текущий этап — M5: замена геометрической заглушки игрока на оригинальный арт без изменения правил боя. После проверки героя следующий этап — M6: звук и визуальное усиление попаданий.

Известные ограничения текущей версии:

- соперник и арена пока представлены геометрическими заглушками;
- звук отсутствует;
- баланс AI остаётся предварительным и будет уточняться после playtest.
